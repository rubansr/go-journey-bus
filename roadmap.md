# NXTIXA Go roadmap

## Phase 1 — Tamil Nadu network + premium search
- [ ] Location/stop/route/schedule tables, admin-extendable (no code change to add places)
- [ ] From/To autocomplete (Tamil + English), GPS, recent places, today/tomorrow/calendar, passengers
- [ ] Results: full bus detail, sorting + filters
- [ ] Seed realistic TN private-bus network and schedules

## Phase 2 — Booking journey
- [ ] Boarding/dropping point selection in flow
- [ ] Saved passengers, favourite routes, Quick Book / Book Again
- [ ] Payment retry + auto refund case, payment/booking/refund statuses
- [ ] Polished empty/error states

## Phase 3 — Tickets
- [ ] Offline ticket, PDF download, print
- [ ] WhatsApp e-ticket + resend, email fallback, journey alerts
- [ ] Notification centre with mark-all-read

## Phase 4 — Safety, tracking, fare prediction
- [ ] Live tracking map, next stop, ETA, progress, boarding countdown
- [ ] Emergency SOS + emergency contacts
- [ ] Women safety options and reporting
- [ ] Fare prediction, trend graph, fare-drop alerts

## Phase 5 — Dashboards
- [ ] Traveller dashboard (all sections)
- [ ] Admin portal: buses, routes, stops, schedules, bookings, users, refunds, tracking, analytics, revenue reports

## Phase 6 — Experience polish
- [ ] Premium blue/purple/white identity, motion, theme memory
- [ ] Mobile bottom nav + active trip bar
- [ ] Accessibility + Elderly Friendly Mode
- [ ] Full Tamil/English coverage incl. Tanglish
- [ ] Voice booking with confirm-journey step

## Phase 7 — AI assistant upgrade
- [ ] Fare advice, boarding guidance, tracking answers, best-pick modes
- [ ] Natural-language search prefill (Tamil/English/Tanglish)

## Blocked / needs input
- WhatsApp delivery credentials (Twilio or Meta Cloud API)
- Map tile token for real maps (otherwise stylised route progress)
